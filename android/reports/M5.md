## Acceptance checklist (copied from the plan + owner extras)
- [ ] Settings: concurrent downloads, connections per file, speed limit, Wi-Fi only, resume on boot, default HLS quality, notifications, theme (system/light/dark). Values persist in Room and survive process death.
- [ ] Custom save folder via Android folder picker (SAF). Plan allows a flag if hard; say which was chosen and why.
- [ ] Battery-optimization prompt that explains why, does not nag, with a short note for aggressive phone makers.
- [ ] Free-space check before pre-allocating a file, with a clear error.
- [ ] Error taxonomy: short human messages instead of raw exception text, and a "copy error" button that redacts cookies, tokens and Authorization.
- [ ] Logging to a rotating file, viewable and exportable from Settings. Never log cookie values or keys.
- [ ] Memory safety: never hold a whole segment or file in memory. Use bounded buffers, including in the HLS path.
- [ ] B7 (minor, carried): page-to-app bridge can be called from any frame. Mitigate (show host / ignore unrelated frames) or record why we accept it.
- [ ] Android 15 dataSync onTimeout: if emulator time is granted, shorten the timeout in developer settings and document exact steps. Otherwise NOT RUN.
- [ ] M7 decision recorded: NewPipeExtractor for YouTube only, behind SiteResolver. yt-dlp / X / Instagram / TikTok later. Do not start M7. PAGE_RESOLVER items stay as they are.
