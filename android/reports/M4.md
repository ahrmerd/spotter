## 1. What was built
- `engine/hls/HlsPlaylist.kt`: master/media parser for `#EXT-X-STREAM-INF`, `#EXT-X-MEDIA` AUDIO, `#EXT-X-KEY`, `#EXT-X-MAP`, `#EXT-X-BYTERANGE`, relative/absolute URLs and query strings. Best variant = highest bandwidth, then height. Default audio = `DEFAULT=YES` with a URI.
- `HlsDownloader` + `HlsHttp`: fetch playlist (2 MiB cap), VOD only, SAMPLE-AES/DRM fail closed, ~8 parallel segments, per-segment retry with `evictAll` on `IOException`, resume by `PartRecord` index, AES-128 CBC with IV from the tag or the media-sequence number. Captured Referer/Origin/User-Agent replayed; cookies from `CookieSource` at request time for playlist, segments and the key. Internal `X-Spotter-Variant` / `X-Spotter-Audio` are stripped on the wire.
- MPEG-TS sniff: `0x47` every 188 bytes; junk prefix skipped. fMP4: concat init + fragments to `.mp4`. TS remux: `MediaMuxerRemuxer` on device; if a codec cannot go in MP4, keep `.ts` and put the reason on the DONE row.
- Quality picker dialog (resolution · bitrate), default **Best**. Sniffer PLAYLIST `.m3u8` items go here; DASH `.mpd` is refused with a message.
- Progress: `size` = segment count, UI/notification `"N / M segments"`, determinate bar. Playlist byte length is never shown as the video size.
- Fixtures: `android/tools/make_hls_fixtures.sh` → `app/src/test/resources/hls/` (plain, AES-128 sequence IV, fMP4 MAP, master+audio, `.jpg` names, junk header).

## 4. Deviations from the plan (each with the reason)
- JVM tests remux MPEG-TS with host `ffmpeg` (`FfmpegCliRemuxer`). `MediaMuxer` is Android-only and is what `SpotterApp` injects (`MediaMuxerRemuxer`). The plan's remuxer is still the production path.
- Chosen variant/audio are passed as `X-Spotter-Variant` / `X-Spotter-Audio` headers (stripped by `HeaderUtils`, never sent). No Room schema v3.
- HLS parallelism is 8, independent of `connectionsPerFile` (byte-range parts).
- Playlist bodies are bounded at 2 MiB. Segments stream to disk with a 64 KiB buffer.
- B7 (JS bridge on every frame) is unchanged; minor, host is shown on the sheet.
